# Before Session 1 — One-time setup (~20 min)

Welcome! Session 1 is your orientation session, so there's no pre-read with exercises like future sessions will have. But there are a few one-time setup steps. Do these **before** we meet, so we can hit the ground running.

---

## 1. Google account (2 min)

You'll need a Google account for Colab and Drive. Most likely you already have one. If not, create one: [accounts.google.com](https://accounts.google.com)

## 2. Open Google Colab and run one cell (5 min)

Colab is where you'll write and run Python code for this entire track. It's free, runs in the browser, no installation.

1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Click **New Notebook** (top left, or `File → New notebook`)
3. You'll see a cell that looks like an empty text box. Click in it.
4. Type exactly this: `print("Hello, Sanketana!")`
5. Press **Shift + Enter** to run it
6. You should see `Hello, Sanketana!` appear just below the cell

If you got that output — you're ready for Session 1. 🎉

If you got an error or are stuck — no worries. Screenshot what you see and send to the instructor on WhatsApp. We'll sort it out.

## 3. Bookmark three links (1 min)

- Your **Drive folder** for this course (you'll have received a link)
- [Colab](https://colab.research.google.com)
- [NHANES homepage](https://wwwn.cdc.gov/nchs/nhanes) — the government data source we'll use from Session 6 onward. Just bookmark it; don't go exploring yet.

## 4. Read two things in your Drive folder (10 min)

Open your Drive folder. Read:

1. **`start-here.md`** — how the course works, what's expected of you, what to expect of us
2. **`final-project-rubric.md`** — yes, on Day 1. This is what you're building toward.

Don't panic about the rubric. You're not supposed to understand all of it yet. Just skim it so you know the finish line exists.

## 5. That's it — see you in Session 1

Come to Session 1 with:
- Colab open in a browser tab
- Your Drive folder bookmarked
- Any questions from the reading
